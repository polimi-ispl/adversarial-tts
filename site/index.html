Setup guide
Text → mel → WAVWith your configured assets
# Install once
python -m pip install -e ".[acoustic,vocoder]" huggingface_hub

# Download checkpoints
hf download Cocii/adversarial-tts --local-dir checkpoints

# Select V, VR, or VRT
python inference.py \
  --config checkpoints/tts.yaml \
  --text "Hello, this is a speech synthesis example." \
  --reference-embedding /path/to/speaker.npy \
  --reference-mel /path/to/reference-mel.npy \
  --vocoder VRT --output-dir outputs/example

Requires an existing model bundle, speaker embedding, and reference mel. Models are not downloaded automatically.

About the recordings

The collection includes four training-set speakers and two unseen voices. Gorou and Yae Miko are character voices from Genshin Impact by miHoYo, as identified in the original collection. Speaker references contain different text from the synthesized prompts; excerpts are reconstructed from source filenames.

The recordings illustrate the methods; detector metrics are evaluated separately in the paper. No blanket license is asserted for the recordings or model weights.
