# 模型与条件输入

从 **[Hugging Face](https://huggingface.co/Cocii/adversarial-tts/tree/main)** 下载声学模型、V / VR / VRT 声码器、配置和发音词典：

```bash
python -m pip install huggingface_hub
hf download Cocii/adversarial-tts --local-dir checkpoints
```

合成时使用 `checkpoints/tts.yaml`。配置中的模型路径相对于该文件解析，`SHA256SUMS` 记录了模型和配置的校验值。使用其他检查点时，请将模型文件保存在源代码版本控制之外，并在自己的资源包 YAML 中指定路径。

## 资源包结构

请参阅 `configs/tts.example.yaml`。`acoustic` 映射要求包含 `checkpoint`、`preprocess`、`model` 和 `lexicon`；检查点保存完整训练分箱时，`stats` 可省略。`vocoders` 映射包含可用的任意 V/VR/VRT 条目，每个条目都需要 `checkpoint` 和 `config`。只会加载所选变体。相对路径以资源包 YAML 所在目录为基准，而非 shell 的 cwd。

声学检查点必须包含基于参考条件的 `AdaSpeech_spkr_en_cn` 实现所对应的 `model` 状态字典：`spk-type: spk`、`language_speaker.separated: false`、80 通道梅尔频谱/postnet，以及 512 维参考嵌入。模型层、隐藏层大小、符号词表、音高/能量分箱及检查点键必须匹配。该模型通过双语前端接受英文或普通话文本；程序不会静默替换为其他单语/XLSR 架构。

提供 `stats.json` 时，其中应包含检查点预期的原始音高和能量数值统计信息，包括分箱端点。未提供时，运行时仅提取 `variance_adaptor.pitch_bins` 和 `variance_adaptor.energy_bins` 的端点，在私有临时目录中满足未修改的模型构造器要求。随后严格加载状态，恢复**每个已保存的分箱值**，包括不均匀间隔，并逐字节核对。缺失、非有限、未排序或形状不正确的分箱会被拒绝。这不会恢复训练均值/标准差、数据集元数据或原始规范化流程。

词典路径需要显式指定，所有条件输入均独立于文件名或说话人映射提供。声学加载器要求 PyTorch 2.6+，始终使用 `weights_only=True`。有限的 NumPy float32/float64 标量/dtype 白名单兼容旧优化器元数据；任意自定义 pickle 对象仍被拒绝。原始检查点仅被读取，不会被修改，也不会回退到不受限的 pickle 加载。

V/VR/VRT 检查点各自包含 `generator`。配置必须确定精确的架构和条件输入约定。恢复声码器训练还需要判别器/优化器/步数状态；只有生成器的检查点并非完整训练检查点。

## 梅尔频谱约定

默认声学配置使用 22050 Hz、FFT/窗口 1024、hop 256、80 个频带和 0–8000 Hz。所选声码器必须在这些字段及其上采样倍数乘积上保持一致。仅凭默认值无法确定训练过的检查点。

已检查的声学参考前端会在两侧各反射填充 n_fft/2 个采样点（默认值为 512）；BigVGAN WAV 前端在 `center=False` 时填充 (n_fft-hop)/2（384）。BigVGAN 还会在幅度计算的 sqrt 内部加上 1e-9；声学前端没有此操作。已检查的两条路径都使用自然对数，下限为 1e-5；模型的数据集/导出路径中没有单独的梅尔均值/方差规范化。外部预处理可能有所不同。

统一文本推理会将声学模型**预测的 postnet 梅尔频谱**直接传给采用该条件输入约定训练的声码器。它按预测的真实长度裁剪，并将 BTC 转置为 CT。它不会重新执行波形提取，不会强制参考前端与声码器前端在数值上等价，也不会自行构造填充/规范化修复。请使用匹配的训练配置，并单独验证训练过的检查点质量。

参考梅尔频谱为声学模型提供话语条件输入；它不是生成的话语。预先计算的说话人嵌入提供身份条件输入，不能替代参考梅尔频谱。参考音频可以提供前述梅尔频谱；可选的 pyannote 则可提供其匹配的 512 维身份向量。

## 论文检查点验证

在声称复现论文之前，请验证精确的声学模型/声码器/检测器权重和源代码版本、环境、预处理/数据划分、检测器类别极性及评估流程。随机检查点执行测试并非质量或检测测量。在发布任何权重、训练数据和语音/参考材料之前，必须确认其许可证与权限。

本地验证已严格匹配完整尺寸声学模型状态及所有 V/VR/VRT 生成器状态。随后，使用完整尺寸声学权重、合成身份条件和公开参考音频，三个声码器均从同一预测梅尔频谱生成了音频；声学模型使用 CPU，声码器显式使用 MPS，并禁用 CPU 回退。仅用于推理的声学检查点精确保留原始模型张量，省略优化器状态。这些检查不代表原始说话人身份、训练统计恢复、音质、检测器指标或训练/恢复流程的复现。
