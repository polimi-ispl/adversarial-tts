# 训练

项目包含声学模型和声码器训练实现，保留了它们的模型定义、训练前向方法、损失计算和检查点参数键。对受支持推理路径的更改，不代表已经恢复原论文的完整训练实验。

## 声学模型

声学训练入口为 `acoustic/train_en_cn.py`，模型/预处理/训练 YAML 位于 `acoustic/config/` 下。微调入口为 `acoustic/finetune.py`。这些程序需要外部预处理语料，其中包含梅尔频谱、音高、能量、时长、音素聚合数据、说话人元数据/嵌入及配套统计信息。运行/恢复实验之前，请取得原始检查点对应的环境和清单。

请在独立环境和组件目录中运行训练；推理依赖组不代表覆盖全部预处理/训练需求。`acoustic/requirements.txt` 是包含冲突旧版固定依赖的历史记录，并非受支持的推理安装方案。请针对目标实验审查其训练依赖和配置路径，不要直接将其安装到已有推理环境中。

## 声码器与对抗目标

声码器训练入口为 `vocoder/train.py`。V 表示基线合成，VR 以 RawNet2 为目标，VRT 以 RawNet2/TSSD 为目标。预期方法将 AASIST 留出，不参与声码器微调。当前实验训练器包含未启用/被注释的检测器路径，以及尚未解决的梯度/标签/优化器/损失/衰减差异。此外，它还通过 RawNet 辅助代码导入了缺失的 `audio_utils.py`。

解决这些差异需要原始 V/VR/VRT 训练脚本、检测器权重/配置、类别顺序、数据划分/预处理记录和日志。不要将恢复注释代码或更改损失视为经过验证的重建。在原始实验资源包可用之前，训练行为保持不变。

## 恢复训练与评估

请使用精确匹配的模型/配置/检查点。恢复声学训练可能不仅需要 `model`，还需要优化器状态。恢复声码器训练需要判别器和优化器状态、epoch/步数及生成器。在完整运行之前，请先在原始受支持硬件上验证一条小规模训练/恢复/评估路径。与论文手稿比较之前，请确认得分极性，以及 AUC/EER/平衡准确率定义的一致性。推理测试不代表已经执行训练，也不代表取得了论文质量的结果。
